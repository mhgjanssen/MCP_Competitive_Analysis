2. Key Updates This Week

Reltio New

Summary: Reltio 2026.2 reaches GA on Oct 23, 2026 (per the official release-cadence page). The marquee change: Reltio AgentFlow is renamed “Autonomous agents”, with capability-level renames (AgentFlow Unstructured → Unstructured augmentation, Agent Builder → Custom agents, Agent Marketplace → Discover agents). Long Running Tasks (GA) let autonomous and custom agents work through large record sets in the background on an isolated per-tenant runtime, with per-record status, confidence score, reason, trace and CSV/JSONL export. Unstructured search (GA, part of Unstructured augmentation) turns documents into AI-searchable knowledge bases, grounding custom-agent answers in enterprise content. Reltio's Autonomous agents overview docs explicitly state the capability is “built on the Model Context Protocol (MCP) server,” enforcing RBAC, data masking and audit policies. The Oct 19 Gartner IT Symposium session with Pfizer (Nishith Trivedi, Enterprise Data Governance / Global MDM Lead) was delivered: Pfizer projects an 80–90% cut in due-diligence time and a 30–40% cut in stewardship backlog from the agentic AI + MDM approach.

Why it matters: The rename from “AgentFlow” to “Autonomous agents” normalises Reltio's naming with the SAP + enterprise category (SAP AI Agent Hub, Autonomous Suite) and positions “autonomous master data governance” as a shipping product category, not a slide. The MCP Server is still the plumbing, now with explicit customer-grade benchmarks via Pfizer.
