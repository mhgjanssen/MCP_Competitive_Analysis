  • SAP officially discontinues the SAP BTP-based SAP Master Data Governance, cloud edition (SAP Community blog, Sept 30). Future MDM footprint = SAP MDG on S/4HANA (central governance at source) + SAP Reltio (enterprise-wide unification) inside SAP Business Data Cloud — first time SAP publicly ends a cloud MDG SKU and formally cedes the non-SAP unification role to Reltio.

Agent Bundle beta adds headless Agent Tasks and Workflow Engine integration.

  • Cross-vendor: Nine weeks post-spec, still zero MCP 2026-07-28 compatibility statements across the tracked set. Pimcore's “Datahub Simple REST MCP reaches final” is the week's closest native-MCP GA event.

2. Key Updates This Week

SAP MDG New

Summary: The Sept 30 SAP Community blog “The Evolution of SAP Master Data Governance with SAP Business Data Cloud” (Andreas Seifried, SAP) formally announces the discontinuation of the SAP BTP-based SAP Master Data Governance, cloud edition: existing subscriptions honoured through contract end, no renewals, free tier withdrawn, phased out of BTPEA/CPEA/PayGo. SAP positions SAP MDG (S/4HANA, central governance at source) and SAP Reltio (enterprise-wide unification across SAP + non-SAP) as the two complementary MDM components inside SAP Business Data Cloud. SAP S/4HANA Cloud Private Edition and Public Edition are the recommended MDG deployment targets.

Why it matters: SAP has publicly ceded the non-SAP unification role to Reltio and simplified its MDM story to a two-SKU architecture — materially sharpens the competitive frame Stibo Systems faces inside SAP accounts, especially for cross-system / non-SAP master-data use cases.

Source:
  • The Evolution of SAP Master Data Governance with SAP Business Data Cloud (SAP Community, Sept 30, 2026)
Pimcore Updated

Summary: Pimcore Platform Version 2026.3 GA (Sept 30, 2026). Three MCP / agent-relevant items: (1) Datahub Simple REST MCP support reaches “final” (previously beta); (2) Pimcore evolves into a full OAuth 2.0 server built on existing Pimcore user accounts — standardised authentication for external AI agents, chat assistants and MCP integrations without a separate identity layer; (3) Pimcore Embeddings — a new vector-embeddings service for images and textual metadata enabling semantic search and duplicate / near-duplicate detection across assets and data objects via an adapter-based provider model. Pimcore Agent Bundle stays beta but now supports headless Agent Tasks and integrates with the Pimcore Workflow Engine. First post-Tenzing-majority-stake product release.

Why it matters: Final MCP + native OAuth 2.0 + headless agent tasks + embeddings-powered semantic search give Pimcore one of the most complete open-core PIM/MDM stacks for agent-ready, governed data access in the tracked set.

Source:
  • Pimcore Platform Version 2026.3: Faster Data Operations, Extensible Portals, and the Next Step Toward Intelligent PXM (Pimcore blog, Sept 30, 2026)
Reltio Updated

Summary: Reltio 2026.1.11.0 PRD Sept 25, 2026. First release post-SAP close to productise SAP-branded content: four new “SAP Reltio Velocity Packs” — SAP S/4HANA (business partners, materials, finance), Mill Products & Mining, Retail (customers across channels, GS1 identifiers, SAP S/4HANA for Retail mappings), and Consumer Packaged Goods (GDSN publication, trade data).
