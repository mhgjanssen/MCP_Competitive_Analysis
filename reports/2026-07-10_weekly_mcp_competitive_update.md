3. Notable Patterns
- Multi-agent orchestration is quickly becoming table stakes in PIM/PXM: Syndigo Synapse (March), Salsify SalsifyIQ (May) and now Akeneo Agentic Ziggy (July) all follow the same "governed product data → MCP surface for external agents → in-platform multi-agent orchestrator for internal work" pattern; the debate has shifted from "do you have MCP?" to "who orchestrates the agents you run on top of MCP?".
- Governance is being pushed inside the orchestration layer, not just the data layer — Akeneo's "governance controls and approval mechanisms built into every step" echoes Pimcore's Agent SDK ("agents subject to the same permissions as human users"), Reltio AgentFlow Agent Builder ("prompt security scanning, auditability") and Informatica's Agent Fabric Context Catalog. The category is converging on human-in-the-loop-by-default as the default governance posture.
- Trade press is starting to treat "agentic PXM" as a distinct competitive category alongside SEO and traditional ecommerce ops (IT Brief, Stellagent, AI Agent Store) — a signal that MDM/PIM vendors without a public multi-agent orchestration story will increasingly look feature-behind in analyst and buyer conversations.
