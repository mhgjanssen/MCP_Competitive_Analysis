Reltio New

Summary: Reltio 2026.2 Preview rolled to Development and Test tenants today, Oct 16, 2026 per the official release cadence; GA to Production is Oct 23. The Oct 21 Release Overview Webinar page confirms the 2026.2 scope: advanced hierarchy management (including attribute inheritance), agent-powered search in unstructured data sources, autonomous data stewardship agents, new industry-specific and SAP S/4HANA Velocity Packs, zero-copy integrations with Google BigQuery and Amazon Redshift, LLM-based matching enhancements and 360-degree entity profile improvements, an integrated development experience, and a SAP Cloud Integration Platform connector. Oct 15 Reltio Community Show “Autonomous agents: The next frontier in data management” (Sara Brams-Miller blog, Aleem Javed demo) published the first operational benchmark for autonomous AgentFlow: a single job processed 20,000+ records in ~11.5 hours using ~150 parallel workers with 91% correct enrichment decisions; an ROI model on a million partially-verified addresses estimates $4.8M with autonomous agents vs $13.3M manual (~64% cheaper). Roadmap: bulk review (steward decides on groups), Agent Plan (cost + latency optimisation), autonomous mode for custom Agent Builder agents, and agent memory so past steward decisions reduce future reviews.

Why it matters: 2026.2 is the first Reltio major release to productise autonomous data stewardship agents with operational benchmarks and ROI numbers — moving the agent story from assistance to measurable work replacement. The agent-powered search on unstructured sources and the SAP CIP connector complete the integration path with the SAP channel the Sept 25 / Oct 9 Velocity Packs opened.

3. Notable Patterns

  • The first Gartner PIM Magic Quadrant is this week's dominant competitive event. Six of nine tracked vendors are Leaders (Akeneo, Salesforce/Informatica, Inriver, Salsify, Syndigo, Stibo). Primary-source press releases arrived in a tightly clustered Oct 15 wave; Pimcore has not yet positioned itself. For enterprise buyers, PIM shortlists will converge on the Leader cohort and the MCP + agent-governance story — explicitly cited by Gartner as a growth driver — becomes a Leader-level qualification.
  • The agent-governance arms race is now a product-level race, not a messaging race. Reltio 2026.2 Preview ships autonomous data stewardship agents with hard benchmark numbers (91% correct on 20,000+ records in 11.5 hours; 64% cost reduction). Profisee 2026 R3 ships Aisey AI that configures FastApps / forms / matching strategies in conversation. SAP embeds OpenShell hardened runtime inside the SAP Business AI Platform for secure, auditable agent execution. All shipping product capabilities, not roadmap promises — a step-change from the mid-2026 “AI assistant” wave.
  • MCP has moved from vendor claim to customer case study. Akeneo's Oct 14 DwyerOmega blog is the first first-party Akeneo customer story explicitly built around Akeneo MCP in a production Microsoft Fabric pipeline. Reltio's Oct 19 Gartner IT Symposium session with Pfizer frames governance + trust as the core agentic-AI lesson. The vendors that reach the “named references for MCP in production” milestone first are likely to set the H1 2027 pace.
  • Still zero MCP 2026-07-28 compatibility statements across the tracked nine vendors (eleven weeks post-spec). Informatica MCP docs still reference 2025-06-18. None of the Oct 12 PIM MQ announcements call out a specific MCP protocol version either.
