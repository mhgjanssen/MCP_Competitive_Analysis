## 3. Notable Patterns

- MCP is quietly evolving from an integration protocol into a customer-facing extensibility surface. Inriver's MCP Code Writer, Pimcore's MCP-based Agent SDK, and Reltio's Agent Builder on top of the Reltio MCP Server all treat MCP as the "how you extend the platform," not just "how AI reads the platform."
- Cross-cloud MCP breadth has become a lock-in narrative for Informatica. Regional trade press in different markets is repeating the same five-hyperscaler list, effectively cementing "which clouds does your MCP run on" as a buyer question.
- PIM/PXM vendors continue to bifurcate their MCP messaging into (a) data-operations governance and (b) commerce outcome / "getting recommended by AI." Salsify's July 6 webinar and Inriver's "system of work" framing both push MCP into the second bucket.
