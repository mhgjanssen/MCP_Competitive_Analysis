3. Notable Patterns
- Headless / MCP-callable data platforms are becoming the dominant agentic-AI architecture narrative: Informatica's Day 1 framing — "every IDMC capability is a reusable, governed service via MCP" — mirrors the path SAP/Reltio took at Sapphire and is now the de facto positioning bar for MDM vendors.
- The MCP surface is broadening from headline product pages into integration/runtime layers: SAP HANA Cloud, SAP Integration Suite, Microsoft Foundry Tools Catalog, AWS Agent Registry, Databricks Agent Bricks, Snowflake Cortex AI, Google Cloud Gemini Enterprise. MCP is being treated less like a feature and more like a connectivity standard customers expect by default.
- A second-order theme is unified governance over both data AND agents: Informatica's Agent Fabric Context Catalog and SAP's AI Agent Hub now both explicitly claim to inventory and govern MCP servers and AI agents alongside data assets — a meaningful shift in scope vs. last week.
